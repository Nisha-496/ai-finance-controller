# AI Finance Controller

Razorpay AI Buildathon 2026 — Track 04 ("Run the books and the cash position").

A reconciliation platform for multi-source financial matching (orders, payments,
settlements). The matching engine — normalization, exact matching, fuzzy scoring,
confidence tiering — is **100% deterministic**. AI is used for exactly two things:
explaining exceptions in plain language and answering questions about live
reconciliation state. It never touches the matching logic, and it never gets
raw database access — see [ARCHITECTURE.md](./ARCHITECTURE.md) for the full design.

**Measured accuracy** (180-deal held-out set, never shown in the demo): 100% match
precision, 90.7% recall, **0% false auto-match rate**. Full numbers and how they're
computed: [docs/metrics-report.md](./docs/metrics-report.md).

## Quick start

```bash
npm install

# Local Postgres — no separate install needed
npm run db:dev        # starts a local Postgres, prints the connection URL
cp .env.example .env  # then paste in the DATABASE_URL it printed (use 127.0.0.1, not localhost)

npm run db:migrate    # create the schema
npm run demo:reset    # seed + reconcile the demo dataset

npm run dev           # http://localhost:3000
```

For the AI layer (exception explanations, chat), add a free Google Gemini key to
`.env` — no billing required, see `.env.example` for how to get one.

## Scripts

| Command | What it does |
|---|---|
| `npm run dev` / `build` / `start` | Standard Next.js commands |
| `npm run db:dev` | Start a local Postgres (via `prisma dev`) |
| `npm run db:migrate` | Apply the Prisma schema |
| `npm run db:studio` | Browse the database |
| `npm run demo:reset` | Wipe and reseed the demo dataset, fully reconciled |
| `npm run eval` | Run the full held-out set and regenerate `docs/metrics-report.md` |
| `npm run script <path>` | Run any one-off TypeScript script with `.env` loaded |

## Project structure

```
src/
  app/                 pages + API routes (Next.js App Router)
  components/          UI components (shadcn/ui-based)
  lib/                 reconciliation engine, AI layer, normalization
  lib/queries/          shared data-access functions (used by both pages and API routes)
  generated/prisma/    generated Prisma client (gitignored)
prisma/
  schema.prisma        5-table schema — see ARCHITECTURE.md Section 12
data/
  demo/                small dataset for the live walkthrough
  eval/                held-out dataset + ground-truth.json for measured accuracy
scripts/               generators, verification scripts, demo reset, evaluation
docs/
  development-log.md   real issues hit during the build, as they happened
  metrics-report.md    measured accuracy, regenerated by `npm run eval`
  pitch-script.md       submission video script
```
